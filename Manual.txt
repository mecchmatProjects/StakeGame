5) MATH SDK STRUCTURE EXPLANATION (PRACTICAL)
====================================================================
This section maps what you edit and what the engine generates.

A) Game-specific code (edit here for this game)
- math-sdk/games/treasure_dice/game_config.py
  Purpose:
  - Defines game_id, RTP, BetModes, distributions, max win logic.
  - Loads mapping spec from treasure_dice_phase3_mapping_spec.json.

- math-sdk/games/treasure_dice/gamestate.py
  Purpose:
  - Implements deterministic outcome selection and event emission.

- math-sdk/games/treasure_dice/game_events.py
  Purpose:
  - Builds ordered event payloads used in books and replay.

- math-sdk/games/treasure_dice/run.py
  Purpose:
  - Entry point for simulation generation.
  - Calls create_books and generate_configs.

B) Shared engine internals (usually do not edit for game delivery)
- math-sdk/src/config/
- math-sdk/src/state/
- math-sdk/src/write_data/
- math-sdk/src/events/
Reference:
- math-sdk/docs/math_docs/directory.md

C) Generated artifact areas
- math-sdk/games/treasure_dice/library/configs/
- math-sdk/games/treasure_dice/library/publish_files/
- math-sdk/games/treasure_dice/library/lookup_tables/
- math-sdk/games/treasure_dice/library/books/

These are generated outputs consumed by publication packaging steps.

====================================================================
14) TROUBLESHOOTING
====================================================================
Problem: run.py fails on missing module
Action:
- Ensure your current directory is math-sdk before running.
- Ensure Python environment has required dependencies.

Problem: no compressed books generated
Action:
- Confirm compression flag in run.py is True.
- Confirm create_books completed without runtime errors.

Problem: stale lookup files survive between runs
Action:
- run.py contains stale publish lookup cleanup logic.
- Re-run generation after cleanup.

Problem: rounding validation disagreements
Action:
- Verify final policy source is RGS six-decimal settlement model.
- Do not mix display-layer cent rounding assumptions with settlement math.
